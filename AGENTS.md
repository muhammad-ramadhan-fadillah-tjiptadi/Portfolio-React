# Panduan Proyek Web Portofolio

Proyek ini adalah web portofolio front-end (static site).

## Tech Stack & Alat
- ReactJS 19 (Vite 8)
- Tailwind CSS v4 (via @tailwindcss/vite plugin)
- GSAP (animasi)
- OGL (WebGL / 3D)
- Package Manager: `pnpm` (JANGAN gunakan npm atau yarn)

## Perintah Penting
- Run lokal: `pnpm run dev`
- Build: `pnpm run build`
- Lint: `pnpm run lint`
- Preview build: `pnpm run preview`

## Panduan Pengembangan
- Ini adalah static site murni front-end — tidak ada backend atau database.
- Prioritaskan performa: optimalkan ukuran bundle dan assets (gambar, font).
- Tambahkan logging disetiap Operasi yang dilakukan
